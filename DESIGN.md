# Design system

Direction: a calm teaching workspace, warm off-white canvas, ink typography, emerald primary actions, thin borders and restrained shadows. Sidebar anchors the wide dashboard workspace. Its live room prioritizes roster, response counts and question controls. The extension adapts both roles to a narrow side panel: a compact teacher control room and a focused student question view.

Typography: system sans-serif, large compact headings, tabular numbers for metrics and timers. Spacing on a 4px scale. Cards use 16–24px padding and 14px corners. Controls have visible labels, 44px touch targets, focus rings, disabled and busy states. shadcn-style Button based on Radix Slot and class-variance-authority is shared by all React interfaces.

Status vocabulary: Live / Lobby / Ended; Answered / Awaiting / Missed / Not eligible; Connected / Offline; Correct / Incorrect / Ungraded; Pending / Excused / Rejected. Color supplements text. Connection never stands in for participation.

Empty screens explain the next action. Errors remain visible with retry. Reconnect banners explain synchronization; stale data is labeled. Forms retain values on failure. No fake class data on real account screens.
